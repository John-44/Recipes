## Concept

*The Recipe Repo* was born out of a personal need: I found that all the recipes I read for a particular dish seemed to miss out some ingredients, steps or important details. But the missed items in each recipe were different, so by reading 5 to 10 recipes for the same dish, I could arrive at an aggregate recipe that contained the best touches from all.

And wouldn't it be great to have a collection of recipes managed in Git and in Markdown format, that are succinct, pragmatic and straight to the point, and that anybody could provide feedback on or contribute to? That's what *The Recipe Repo* aims to do.

## Principles

The aggregated recipes are shaped and scoped according to the following principles:

| | Principle | What it means |
| :-: | --- | --- |
| 🎯 | **Aim high** | Each recipe should be the best, elevated version, while remaining practical to cook. |
| 🔬 | **Objective&nbsp;purpose** | Every step and instruction should contribute to the dish for a quantifiable reason. |
| ⚡ | **Embrace&nbsp;tech** | Old labour-intensive tools like a mortar and pestle are out. Things like high-speed blenders are in. |
| 🌡️ | **Pragmatic** | Utilise the easiest methods to achieve consistent results, e.g. use thermometers. |
| 🥫 | **Best&nbsp;ingredients** | Always use the best ingredients for the specific recipe.[^1] |
| 🧂 | **No&nbsp;superstitions** | For example, use MSG when it makes sense. |
| ✂️ | **Succinct** | Each recipe should contain only pertinent information, and be short and to the point. No waffling. |
| ⚖️ | **Precise** | Every quantity, timing and temp should be exact, leaving nothing to guesswork. |

[^1]: Counterintuitively, this can sometimes mean using processed instead of fresh, e.g. canned pumpkin purée in [Pumpkin Pie](recipes/Pumpkin_pie.md).

## How the recipes are written

- 📋 **[Recipe_template.md](Recipe_template.md)** defines the consistent Markdown format all the recipes are in.
- 📖 **[Terminology_glossary.md](Terminology_glossary.md)** enforces terminology consistency, so every recipe calls things by the same name.
- 🎨 **[Illustration_style_template.md](Illustration_style_template.md)** defines the style of the masthead images, so they look like one collection.
- 🚫 **[Declined_suggestions.md](Declined_suggestions.md)** lists suggestions that have already been considered and turned down.
- 🤖 **[AGENTS.md](AGENTS.md)** tells AI agents, such as Claude Code and Codex, how to work in this repository.

## Contributing

Bug reports and pull requests are gratefully accepted, and will be reviewed and actioned as appropriate. If you fork this repo, please do try to push any edits and additions back upstream, so others can benefit.

- 🐛 **Spotted a mistake?** [Open an issue](https://github.com/John-44/Recipes/issues), saying which recipe and step it's in.
- 🍳 **Adding or improving a recipe?** Follow the [template](Recipe_template.md) and the [glossary](Terminology_glossary.md), then open a pull request.
- 💡 **Got a suggestion?** Check [Declined_suggestions.md](Declined_suggestions.md) first, in case it's already been turned down.

> [!NOTE]
> As an opinionated editor, I can't guarantee that all change requests will be merged, but I'll try my best.
