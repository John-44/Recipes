# Terminology glossary

This file pins the exact words the recipes in this repository use, so that every recipe calls the same thing by the same name. It lists only terms that at least one recipe uses. The exception is the [tag list](#tags), which holds every tag a recipe can choose from.

Read it before you write or edit a recipe, use its terms exactly, and add any new terms when you finish. The tables aren't in plain A to Z order, so read [How the tables are ordered](#how-the-tables-are-ordered) before you add anything. The full rules are in [Terminology](Recipe_template.md#terminology) in the recipe template.

## How the entries work

- **Term** is the exact wording to use: the same words, spelling, hyphens, word order and capitals. Terms are written as they'd appear mid-sentence, so most are lower case. Names such as Thai, Kashmiri and Charlotte keep their capitals, and so do headings, labels, titles, places, tags and website names. Give a term a capital first letter when it starts a line or a sentence.
- **Family** (in some tables) groups similar terms, such as Chopping or Peeling.
- **Short name** (ingredients and recipe titles only) is the shortest form to use once something has been introduced. You can drop words from the term as far as its short name, so "raw king prawns" can become "king prawns" or "prawns", but never "shrimp".
- You can add a word that describes the size or state you need, such as "1 small onion", "a large saucepan" or "frozen raw prawns", unless the result is in the **Don't use** column.
- **Don't use** lists other names for the same thing. Never use them for that thing, even where they're correct English.
- **Notes** explain anything that's easy to confuse with the term, and how to use it.
- `{Curly brackets}` mark a part you fill in, as in the recipe template.
- Units and amounts (g, ml, tbsp, cans and so on) follow the template's [measurement rules](Recipe_template.md#measurements). Section headings, summary box labels (such as **Makes**), storage labels (such as **Fridge**) and credit labels (such as **Original author**) are set by [the template](Recipe_template.md#the-template) itself. None of these are repeated here.

## How the tables are ordered

Every table is ordered so that similar terms sit together and are easy to compare. Just above each table, an **Order** line or a **Families** list says how.

- **Families:** in a table with a **Family** column, the rows are grouped by family, and the families come in the order given above the table. A **Families** list can include families with no terms yet, to show where future terms go.
- **Scales:** within a family, or in a table without families, terms run along a scale wherever there's a natural one, such as least heat to most, finest to coarsest or mildest to hottest. Where there isn't one, they're A to Z, ignoring brackets, quote marks and italics.

**To add a term:**

1. Find the table it belongs in, and read the **Order** line or **Families** list above it.
2. If the table has families, choose the family the term belongs to. If none fits, add a new family to the **Families** list where it fits best, and say how its terms are ordered.
3. Insert the term at its place in that order. Never just add it to the end of a table.

### Dishes

Dishes the recipes mention, from any cuisine, with their English names and their original names.

- Write English names in lower case, apart from names such as Thai. Title Case is only for recipe titles.

- Leave a cell empty when the recipes don't use a name for it.
