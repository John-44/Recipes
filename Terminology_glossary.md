# Terminology glossary

This file pins the exact words the recipes in this repository use, so that every recipe calls the same thing by the same name. It lists only terms that at least one recipe uses. The exception is the [tag list](#tags), which holds every tag a recipe can choose from.

Read it before you write or edit a recipe, use its terms exactly, and add any new terms when you finish. The full rules are in [Terminology](Recipe_template.md#terminology) in the recipe template.

## How the entries work

- **Term** (the first column of each table) is the exact wording to use: the same words, spelling, hyphens, word order and capitals. Terms are written as they'd appear mid-sentence, so most are lower case. Names such as Thai, Kashmiri and Charlotte keep their capitals, and so do headings, labels, titles, places, tags and website names. Give a term a capital first letter when it starts a line or a sentence.
- **Short name** (ingredients and recipe titles only) is the shortest form to use once something has been introduced. You can drop words from the term as far as its short name, so "raw king prawns" can become "king prawns" or "prawns", but never "shrimp".
- You can add a word that describes the size or state you need, such as "1 small onion", "a large saucepan" or "frozen raw prawns", unless the result is in the **Don't use** column.
- **Don't use** lists other names for the same thing. Never use them for that thing, even where they're correct English.
- **Notes** explain anything that's easy to confuse with the term, and how to use it.
- `{Curly brackets}` mark a part you fill in, as in the recipe template.
- Units and amounts (g, ml, tbsp, cans and so on) follow the template's [measurement rules](Recipe_template.md#measurements). Section headings, summary box labels (such as **Makes**) and storage labels (such as **Fridge**) are set by [the template](Recipe_template.md#the-template) itself. None of these are repeated here.
- Each table is in alphabetical order by its first column, ignoring brackets, quote marks and italics. The tag list is the exception: it's grouped, with the tags in each group in alphabetical order.
